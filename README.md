## ⚙️ Использование

1. **Включите Безопасный DNS (Secure DNS):**
   * В **Chrome**: *Настройки -> Конфиденциальность и безопасность -> Безопасный DNS*.
   * В **Windows 11**: *Параметры -> Сеть и Интернет -> Wi-Fi/Ethernet -> Назначение DNS-сервера*.
2. **Скачайте архив** со [страницы релизов](https://github.com/releases).
3. **Распакуйте архив** в удобное место (желательно, чтобы в пути не было кириллицы и пробелов).
4. **Запустите нужный файл:**
   * Запуск без установки: `service.bat` -> `1_russia_blacklist.cmd`

---

## 📄 Краткие описания файлов

* `general.bat` — запуск стратегии вручную (без установки службы).
* `service.bat` — управление службой и дополнительные функции:
  * **0_install_service** — установка службы в автозагрузку.
  * **0_remove_service** — удаление службы из системы.
  * **check_status** — проверка статуса службы.

## ❓ Распространенные вопросы и проблемы

<details>
<summary><b>После запуска скрипта general* ничего не происходит</b></summary>
<br>

* После запуска стратегии (отдельным bat-файлом или через `service.bat`) должно открыться командное окно (консоль), которую можно убрать в трей задач.
* Если этого не произошло, то см. [#111](https://github.com).
</details>

<details>
<summary><b>Ни одна стратегия не подходит</b></summary>
<br>

1. Запустите командную строку от имени администратора.
2. Последовательно введите команды в консоли:
   ```cmd
   ipconfig /flushdns
   netsh int ip reset c:\resetlog.txt
   netsh winsock reset
   ```
3. Перезагрузите компьютер.
</details>

<details>
<summary><b>Не работает телеграм (веб версия)</b></summary>
<br>

Запустите `service.bat`, выберите пункт `Update hosts file`. После чего, если ваш `hosts` будет невалидным, то вам будет предложено обновить его самостоятельно:
* Скопируйте весь текст из открывшегося блокнота.
* Откройте файл `hosts` в появившейся папке с помощью текстового редактора, открытого от имени администратора.
* Добавьте в конец файла `hosts` то, что скопировали (или замените, если до этого вы уже добавляли подобное).
* Сохраните и перезагрузите подключение. Если не работает — убедитесь, что файл `hosts` действительно сохранился.

> **Примечание:** Работа не гарантирована. Если не помогло — используйте [Десктоп версию с прокси](https://github.com) или любым публичным.
</details>

<details>
<summary><b>Обход не работает / перестал работать</b></summary>
<br>

> [!IMPORTANT]
> **Стратегии со временем могут переставать работать.** Определенная стратегия может работать какое-то время, но со временем ркн может перестать работать из-за обнаружения. В репозитории представлено множество различных стратегий для обхода. Если ни одна из них вам не помогает, то вам необходимо создать новую, взяв за основу одну из представленных здесь и изменив её параметры. Информацию про параметры стратегий вы можете найти [тут](https://github.com).

* Проверьте, чтобы не было ошибок в запуске `service.bat` -> `run diagnostics`.
* Убедитесь, что адрес ресурса записан в списках доменов или IP.
* Проверьте другие стратегии (`ALT` / `FAKE` и другие).
* Попробуйте полную переустановку (см. раздел ниже).
* См. [#743](https://github.com/issues/743).
</details>

<details>
<summary><b>Как переустановить/обновить полностью?</b></summary>
<br>

1. Сохраните ресурсы/домены, которые вы сами добавляли.
2. Перезапустите устройство.
3. `service.bat` -> `Remove Service`.
4. `service.bat` -> `Run Diagnostics` (если есть ошибки — устраните их) -> в конце `Y`.
5. Удалите папку с запретом.
6. Скачайте последнюю версию [со страницы релизов](https://github.com/releases).
7. Нажмите по архиву -> свойства. Если снизу справа есть галочка «Разблокировать», то нажмите на неё -> применить -> ОК.
8. Распакуйте в новую папку в корне диска (без спец. символов и пробелов).
9. Далее пробуйте запустить различные `.bat` скрипты (стратегии). Проверьте доступность интернет ресурсов — если не работает, то закрывайте программу (в панели задач иконка замочка) и пробуйте другую стратегию.
10. См. найдите рабочую стратегию, можете поставить её на автозапуск — `service.bat` -> `Install Service` -> выбирайте нужную.
</details>

<details>
<summary><b>Не работает игра/приложение с включённым запретом</b></summary>
<br>

* Проверьте, что в игре `.bat` скрипт `--ip-filter` **disabled** и `--ipv6-filter` **none**. Иначе это может затронуть доступность других ресурсов, которые вы не выбрали.
</details>

<details>
<summary><b>При удалении с помощью service.bat, WinDivert остается в службах</b></summary>
<br>

1. Узнайте название службы с помощью команды в командной строке Windows (`Win+R` -> `cmd`):
   ```cmd
   sc queryex type= service state= all | find "WinDivert"
   ```
2. Остановите и удалите службу командами:
   ```cmd
   sc stop название_из_первого_шага
   sc delete название_из_первого_шага
   ```
</details>

<details>
<summary><b>Не работает 📺 YouTube</b></summary>
<br>

* Убедитесь что вы настроили [Secure DNS](https://github.com).
* Отключите блокировщики рекламы, известно что YouTube начал с ними бороться.
* Пробуйте все другие стратегии (если раньше работало, но перестало).
* См. также [#152](https://github.com/issues/152).
</details>
